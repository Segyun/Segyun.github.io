An interactive picker inspired by iOS Control Center pagination controls, reacting in real time to drag gestures and pointer positions.

Supports both horizontal and vertical layout orientations, providing tactile visual feedback where element scale and position adapt fluidly to touch proximity.

Extensible via the `InteractivePickerStyle` protocol to easily customize transformations such as scale, rotation, and opacity curves.
