SwiftUI에서 텍스트 값이 변경될 때 블러(Blur), 오프셋(Offset), 투명도(Opacity) 효과를 결합하여 자연스러운 텍스트 전환 애니메이션을 구현합니다.

단순한 페이드인·아웃을 넘어 타이포그래피 변화에 특화된 여러 트랜지션을 모듈식으로 자유롭게 조합(Composable)할 수 있습니다.

간결한 뷰 수정자(View Modifier) 구문을 지원하여 기존 SwiftUI `Text` 컴포넌트에 최소한의 코드 수정으로 손쉽게 적용 가능합니다.
