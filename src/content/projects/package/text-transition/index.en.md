Implements fluid typographic transition animations in SwiftUI by combining blur, spatial offsets, and opacity whenever text values change.

Goes beyond simple fade effects by providing modular, composable transitions tailored for typographic changes.

Features an intuitive View Modifier API that allows seamless integration with existing SwiftUI `Text` components with minimal code changes.
