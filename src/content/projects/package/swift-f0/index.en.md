---
title: "SwiftF0"
description: "A Swift pitch analysis library estimating fundamental frequency (F0) from audio via ONNX models and converting it to musical notes."
pubDate: 2025-11-01
githubUrl: "https://github.com/Segyun/SwiftF0"
---

Estimates the fundamental frequency (F0, pitch) from audio files or real-time buffers with high accuracy using an ONNX runtime machine learning model.

Converts raw frequency tracks into musical note segments via `NoteConverter` from the values detected by `SwiftF0Detector`.

Architected for frictionless integration into voice analysis, vocal training, and pitch visualization applications across iOS and Swift platforms.
