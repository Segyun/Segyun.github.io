A SwiftUI project inspired by the native iOS Weather application, implementing hourly and 10-day forecast sections within translucent, frosted glass tiles.

Features a responsive header interaction where current temperature and weather conditions smoothly compress as detailed cards scroll upward.

Engineered with flexible grid layouts and modular, reusable UI components that adapt across diverse screen sizes.
