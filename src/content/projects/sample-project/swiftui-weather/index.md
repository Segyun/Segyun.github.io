iOS 기본 날씨 앱에서 영감을 받아 시간별·주간별 기상 예보 섹션과 블러 타일 기반 레이아웃을 SwiftUI로 재현한 프로젝트입니다.

스크롤 동작에 따라 상단 요약 날씨 정보가 축소되고 상세 타일들이 올라오는 매끄러운 반응형 헤더 인터랙션을 구현했습니다.

다양한 기기 화면 크기에 대응하도록 유연한 그리드와 재사용 가능한 모듈형 UI 컴포넌트 아키텍처로 설계되었습니다.
