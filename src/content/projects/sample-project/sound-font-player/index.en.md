An iOS audio sample demonstrating how to load and play SoundFont (.sf2) instruments using Apple's `AVAudioUnitSampler` from AVFAudio.

Connects a responsive SwiftUI piano keyboard interface directly to a real-time low-latency audio engine for responsive touch performance.

Covers the complete virtual instrument pipeline across Core Audio and AVFoundation, including soundbank/preset initialization and audio node routing.
